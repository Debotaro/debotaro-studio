# Supported TSX 1.1 (document schema v1)

The visual editor synchronizes an explicit catalog subset, not arbitrary JavaScript. One managed region starts // @studio:begin and ends // @studio:end. Outside text remains byte-for-byte recoverable, is never executed in editor or executable export, and is exported as custom-code.txt.

Inside: export const studioMeta = {...} with JSON-compatible literals containing document metadata, tokens, theme, tickets and initial state; optional exact annotation Omit<StudioDocument, "nodes"> is supported for strict TypeScript; export function StudioApp() { return (<StudioProvider meta={studioMeta}>...</StudioProvider>); }.

Common visibleWhen property is allowlisted: always, hasSelection, hasResults, empty, loading, error, ready, tab:inbox, tab:activity, tab:customer. It selects runtime conditions without executable expressions. Color aliases and finite numeric aliases are supported. Numeric references apply to layout gap/padding/columns/width/height/grow, responsive overrides, and catalog radius/size/weight. References stay in the document and code; preview/export resolve the same token graph. Existing bounds remain enforced, including integer columns1–12 and font weights in multiples of100. Width fill and height auto are preserved. Numeric strings and CSS expressions are refused; string labels such as $49/month stay literal.

Catalog JSX: Frame, Text, Button, Field, Select, Tabs, Badge, Table, DetailPanel. Every node has unique studioId="stable-id", name="Layer name", optional props={{...}}, layout={{...}}, responsive={{phone:{...}}}, bindings={{value:"query"}}, events={{onChange:{action:"setQuery"}}}, and catalog children. Keys/values pass core catalog, token/event schema. Responsive flex/grid, gap/padding/columns/width/height/alignment/justification/growth. Token strings $semantic.accent / $primitive.violet. Literal object/array/string/number/boolean/null only. No spreads/computed keys/calls/hooks/member JSX/event functions/arbitrary HTML/maps/conditions/interpolation in managed JSX. Bindings/interactions declarative and allowlisted in types.ts.

Unsupported managed syntax refused with locations before applying. Parse errors retain last valid doc/preview and draft. Visual edits regenerate only managed source. Code apply presents diff and server base-revision check; stale drafts cannot overwrite newer work. Round trips compare semantics/IDs/behavior, not formatting. Implementation evidence and its scope are summarized in [VERIFICATION](VERIFICATION.md).

Saved supported outside source survives reload and subsequent visual changes. Cached invalid source becomes a recoverable draft; explicit discard retains the original in recovery. CodeMirror normalizes line endings on text input; the compiler preserves the submitted outside-region strings exactly, including raw CRLF when called directly. No outside source is evaluated or treated as trusted editor code.

Button onClick declarations require literal values for setTab (inbox/activity/customer), setTicketStatus (open/pending/resolved), and assignTicket (fictional assignee name or empty). reloadTickets needs no literal. Fields/selects/tabs/tables supply safe values from their runtime controls. Catalog/core validation rejects action/event/component mismatches before application.
