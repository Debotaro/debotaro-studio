# Attribution and authorship

Debotaro Studio is an independent product conceived and directed by Debotaro. The product brief combines visual design, UI/UX, frontend development, digital products and AI-assisted development. Implementation was developed with Codex using documented requirements, scoped workers and executable verification; this is not a claim that Debotaro manually authored every source line.

The editor is inspired by familiar professional creation tools, including Figma’s canvas/layers/inspector patterns. Debotaro Studio has original branding, interface composition, copy and source; no Figma affiliation, endorsement or novelty claim is implied.

Third-party software includes React/React DOM, TypeScript, Vite, Express, Node.js’s SQLite API, Yjs, Babel parser/types, CodeMirror, Zod, fflate, idb, OpenAI’s SDK and Lucide icons. Test/development tools include Vitest, Playwright, ESLint and jsdom. Exact versions are in package.json/package-lock.json and docs/DEPENDENCIES.md. Each package retains its own license and notices in its distribution; check those before external redistribution.

The project currently uses system font fallbacks, text/CSS-based visuals and Lucide SVG icons. No purchased stock assets, customer data, user interviews or testimonials are included. Every starter ticket/person/company/address is fictional; .example email addresses are deliberately non-customer fixtures. Screenshots must come from the actual running product and state their scope.
